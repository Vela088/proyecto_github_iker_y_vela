Bienvenidos a nuestra página

Hola, bienvenidos a nuestra página web sobre el Mundial de Fútbol 2026. Hemos elegido este tema porque nos gusta el fútbol y nos parece interesante conocer más cosas sobre las selecciones.

En esta web vamos a enseñar algunos equipos, información sobre el campeonato y una pequeña tabla con partidos y resultados de ejemplo.

¿Qué es el Mundial?

El Mundial de fútbol es una competición en la que participan diferentes paises. Los equipos juegan varios partidos para intentar llegar a la final y ganar el mundial.
